# Open WebUI

[← Back to search](README.md)

**Role:** candidate chat interface (alternative to [LibreChat](librechat.md)). **License:** custom "Open WebUI License" (BSD-3-based + branding clause) since v0.6.6 (April 2025). **Not OSI open source** → conflicts with the "open-source" rule unless accepted.

## Benefits
- Most popular option (124K+ GitHub stars cited); first-class [Ollama](ollama.md) and OpenAI-compatible support.
- Multi-user accounts, RAG, web search, plugins/pipelines, voice.

## Weaknesses / must-know
- Branding must stay visible unless ≤50 users per 30 days, written permission, or an enterprise license. Fine for internal use, a problem for white-labelling by VM providers (CloudStack scenario).
