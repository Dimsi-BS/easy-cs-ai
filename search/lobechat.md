# LobeChat

[← Back to search](README.md)

**Role:** candidate chat interface (alternative to [LibreChat](librechat.md)). **License:** LobeHub Community License (Apache 2.0 base plus proprietary conditions): not OSI open source.

## Benefits
- 72K+ stars, agent groups, plugin ecosystem; team "Workspaces".
- Docker deployment with `docker compose`.

## Weaknesses / must-know
- Commercial use allowed unmodified; commercial derivative works need a separate license from the publisher.
- Multi-user auth and database requirements not confirmed from the README.
